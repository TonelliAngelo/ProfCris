PUBLICAÇÃO MANUAL — SITE PROFª CRIS

1. Abra: https://github.com/TonelliAngelo/ProfCris
2. Entre na aba Code.
3. Clique em Add file > Upload files.
4. Extraia este arquivo ZIP no computador.
5. Envie todos os arquivos e pastas extraídos para a raiz do repositório, mantendo a estrutura original.
6. Se o GitHub perguntar sobre arquivos existentes, confirme a substituição.
7. Clique em Commit changes.

ATIVAR O GITHUB PAGES

1. No repositório, abra Settings.
2. No menu lateral, clique em Pages.
3. Em Build and deployment, selecione Deploy from a branch.
4. Em Branch, escolha main e a pasta / (root).
5. Clique em Save.

Após alguns minutos, o endereço esperado será:
https://tonelliangelo.github.io/ProfCris/

IMPORTANTE

- O arquivo index.html e as pastas assets, css e js devem permanecer na raiz do repositório.
- Não altere os nomes das pastas nem dos arquivos de imagem.
- Preserve o arquivo CNAME para manter o domínio www.profacris.com.br.
